# FaceIQ - In-Browser Biometric Face Analyzer

FaceIQ is a client-side craniofacial photogrammetry suite built to evaluate facial symmetry, canthal tilt inclination, neoclassical thirds, and golden ratio proportions directly in the browser using 478 MediaPipe facial landmarks.

## Live Application
Experience the interactive biometric tools here:
👉 **[FaceIQ AI Face Analyzer & Symmetry Suite](https://ai.faceiq-lab.workers.dev/)**

## Key Features
- **Face Symmetry & Attractiveness Test**: Deterministic cranial variance calculation across 32 mirror pairs.
- **Canthal Tilt Detector**: Calculates palpebral inclination angles in degrees.
- **PSL Scale Calculator**: [Official PSL Rating Breakdown](https://ai.faceiq-lab.workers.dev/psl-scale.html).
- **Golden Ratio (Phi 1.618)**: [Golden Ratio Face Calculator](https://ai.faceiq-lab.workers.dev/golden-ratio.html).
- **Face Comparison AI**: [Compare Two Faces Side-by-Side](https://ai.faceiq-lab.workers.dev/compare.html).
- **Zero-Cloud Privacy**: 100% in-browser WebGL/WASM execution. No photos are transmitted or stored.
